# Chatter Toggle for Odoo 20

A clean, responsive toggle button to show or hide the chatter sidebar in Odoo 20 form views.

## Features
- **Maximize Workspace**: Hiding the chatter gives 100% width to form sheets, order lines, and stock operation tables.
- **Persistent State**: The open/collapsed state is saved in `localStorage`, persisting across page navigation.
- **Sleek UX**: In sidebar mode, collapses to a slim 42px strip on the right edge with a vertical expand button.

## Installation
Clone or copy into your Odoo addons path and install:

```bash
./odoo-bin -i chatter_toggle -d <database> -c <config>
```
